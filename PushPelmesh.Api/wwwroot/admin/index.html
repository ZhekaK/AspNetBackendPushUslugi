Ключи доступа

Пользователи

Активация пользователей

Создает пользователей для всех неактивированных ключей доступа и привязывает уже существующих пользователей к их ключам.

Кандидаты

Роли / удостоверения пользователя

Сначала выбери пользователя из таблицы или введи его серию и номер вручную. Роль привязывается именно к паре серия-номер.

Награды

Добавляет запись в модуль наград. Можно выбрать пользователя по серии и номеру или указать ФИО вручную.

Синхронизация календаря

Создает системные события дней рождений для пользователей с указанной датой рождения.

Системные уведомления

Отправляет push-уведомление выбранным пользователям или всем пользователям с web-подпиской.

Получатели не выбраны.

Очистка гостей

Удаляет гостевых пользователей, которые не активны более 7 дней.
