# Пыш-Услуги

ASP.NET Core обслуживает сайт, админ-панель и JSON API одним процессом. Веб-клиент находится в `PushPelmesh.Api/wwwroot` и использует API того же адреса. Unity и отдельная сборка фронтенда для запуска не нужны.

## Запуск

1. Установите .NET SDK 10 и подготовьте PostgreSQL.
2. Задайте `ConnectionStrings__DefaultConnection`, `Jwt__Key`, `Jwt__Issuer`, `Jwt__Audience` и `Admin__Key` в окружении или в локальном `appsettings.Development.json` через секции `ConnectionStrings`, `Jwt` и `Admin`. При старте приложение применяет миграции к указанной БД.
3. Из корня репозитория запустите команду.

   ```powershell
   dotnet run --project PushPelmesh.Api --launch-profile http
   ```

- Сайт доступен на [localhost:5028](http://localhost:5028/).
- [Админ-панель](http://localhost:5028/admin/) принимает `Admin__Key` и хранит его для текущей вкладки.
- [Swagger](http://localhost:5028/swagger/) доступен в режиме Development.

Для Web Push задайте `Vapid__PublicKey`, `Vapid__PrivateKey` и `Vapid__Subject`. На внешнем сервере откройте сайт по HTTPS. Подписка включается в профиле после входа по удостоверению.

Установить сайт отдельным приложением можно из меню поддерживаемого браузера. Кнопка «Установить приложение» появляется внизу страницы, когда браузер предоставляет запрос установки.

## Сборка и проверка

```powershell
dotnet build PushPelmesh.sln
dotnet publish PushPelmesh.Api -c Release -o ./Publish/site
```

Файлы сайта и админки входят в результат `dotnet publish`. Для проверки HTTP запустите приложение с отдельной тестовой PostgreSQL и тестовым ключом администратора. Скрипт требует Node.js 22 или новее и создаёт пользователей, опросы, комнаты и сообщения в подключённой тестовой БД.

[Выкладка на 20DND и перенос production-базы](DEPLOY-20DND.md).

```powershell
node tests/site-smoke.mjs http://localhost:5028 $env:Admin__Key
```

## Отличия от Unity

«Дурак» использует исходные изображения карт, а «Зонг» — исходные грани костей. Карты выбираются щелчком или клавиатурой. Xoxi сохраняет формат статистики и настроек Unity для того же аккаунта. Для браузера реализованы боты с тремя уровнями сложности, поле 10 × 5 и режим двух игроков за одним устройством. Если понадобится точное поведение исходных ботов или анимаций, можно портировать их по сценам либо оставить только Xoxi отдельной WebGL-сборкой.
